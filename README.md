# Progress

Переиспользуемый компонент кругового прогресса на JavaScript и SVG.
Отображает значение от 0 до 100, поддерживает вращение и скрытие.
Работает без библиотек, сборки и сетевых запросов.

## Подключение

Для использования нужны два файла: `scripts/progress.js` и `styles/progress.css`.
Подключи стили, добавь контейнер и создай экземпляр после загрузки скрипта:

```html
<link rel="stylesheet" href="styles/progress.css">

<div id="upload-progress"></div>

<script src="scripts/progress.js"></script>
<script>
  const uploadProgress = new Progress(
    document.querySelector('#upload-progress'),
    { value: 25, label: 'Загрузка файла' }
  );
</script>
```

Конструктор доступен как `Progress` и `window.Progress`. Он добавляет
элемент компонента внутрь контейнера, сохраняя его существующее содержимое.
Каждый экземпляр хранит собственное состояние.

## Конструктор

```js
new Progress(container, options);
```

`container` — существующий DOM-элемент, в который будет добавлен компонент.

| Параметр options | Тип | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `value` | `number` | `0` | Прогресс от 0 до 100 включительно |
| `animated` | `boolean` | `false` | Вращение кольца по часовой стрелке |
| `hidden` | `boolean` | `false` | Скрытие с сохранением места в раскладке |
| `label` | `string` | `'Progress'` | Доступное название для скринридера |

Объект `options` можно не передавать:

```js
const progress = new Progress(document.querySelector('#upload-progress'));
```

## API

### Изменение состояния

| Метод | Аргумент | Действие |
| --- | --- | --- |
| `setValue(value)` | Конечное число от 0 до 100 | Меняет длину дуги |
| `setAnimated(animated)` | `boolean` | Включает или выключает вращение |
| `setHidden(hidden)` | `boolean` | Скрывает или показывает компонент |

```js
uploadProgress.setValue(62.5);
uploadProgress.setAnimated(true);
uploadProgress.setHidden(true);
uploadProgress.setHidden(false);
```

Методы не возвращают экземпляр и не поддерживают цепочки вызовов.

### Чтение состояния

Свойства доступны только для чтения. Для изменений используй методы API.

```js
console.log(uploadProgress.value);    // 62.5
console.log(uploadProgress.animated); // true
console.log(uploadProgress.hidden);   // false
```

### Проверка аргументов

Значения не преобразуются автоматически и не ограничиваются диапазоном:

- `setValue('50')`, `setValue(NaN)` и `setValue(Infinity)` вызывают `TypeError`.
- Числа меньше 0 или больше 100 вызывают `RangeError`.
- Методы `setAnimated` и `setHidden` принимают только `true` или `false`;
  другие типы вызывают `TypeError`.
- Если контейнер не является DOM-элементом, конструктор вызывает `TypeError`.

Дробные значения допустимы. Ошибка обновления не меняет предыдущее состояние.
При создании аргументы состояния проверяются до добавления компонента в DOM.

## Поведение

### Значение

Дуга начинается на 12 часах и увеличивается по часовой стрелке.
При `value = 0` виден только фоновый трек; при `value = 100` кольцо
полностью окрашено в цвет прогресса. Изменение значения применяется сразу.

### Вращение

При `animated = true` кольцо равномерно вращается по часовой стрелке.
Период по умолчанию — 1,5 секунды. Вращение не меняет значение прогресса.
После отключения начало дуги возвращается на 12 часов.

При значениях 0 и 100 вращение может быть визуально незаметным:
одноцветное кольцо выглядит одинаково при любом повороте.

### Скрытие

При `hidden = true` применяется `visibility: hidden`: компонент исчезает,
но сохраняет место в раскладке. Его состояние можно продолжать обновлять.
После показа значение и флаг вращения сохраняются.

Все три параметра независимы. Например, можно скрыть вращающийся компонент,
обновить значение и показать его снова:

```js
uploadProgress.setAnimated(true);
uploadProgress.setHidden(true);
uploadProgress.setValue(80);
uploadProgress.setHidden(false);
// Компонент снова виден, вращается и отображает 80%.
```

## Настройка внешнего вида

Переопредели CSS-переменные на элементе `.progress`:

```css
#upload-progress .progress {
  --progress-size: 160px;
  --progress-color: #005bff;
  --progress-track-color: #eef3f6;
  --progress-duration: 2s;
}
```

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `--progress-size` | `120px` | Ширина и высота кольца |
| `--progress-color` | `#005bff` | Цвет дуги |
| `--progress-track-color` | `#eef3f6` | Цвет фонового трека |
| `--progress-duration` | `1.5s` | Длительность одного оборота |

SVG масштабируется вместе с компонентом: при диаметре 120 px толщина
кольца составляет 10 px. При изменении диаметра толщина меняется
пропорционально. Центр кольца прозрачный.

## Доступность

Корневой элемент имеет роль `progressbar`, доступное название из `label`
и атрибуты `aria-valuemin="0"`, `aria-valuemax="100"`, `aria-valuenow`.
Последний обновляется при каждом успешном вызове `setValue`.
Декоративная часть скрыта от скринридера.

При скрытии компонента устанавливается `aria-hidden="true"`.
Если пользователь включил `prefers-reduced-motion: reduce`, вращение
отключается средствами CSS. При этом свойство `animated` сохраняет
заданное значение, а остальные методы работают как обычно.

## Как устроена отрисовка

В SVG находятся два круга: фоновый трек и дуга прогресса.
У дуги `pathLength="100"` нормализует длину окружности, а
`stroke-dasharray="100 100"` задаёт штрих длиной в полную окружность.
Метод `setValue` устанавливает `stroke-dashoffset = 100 − value`,
определяя видимую часть дуги.

Поворот `rotate(-90 60 60)` переносит начало дуги с трёх часов на двенадцать.
Плоские концы штриха (`stroke-linecap: butt`) позволяют отображать нулевое
значение без остаточной точки. Вращение применяется к внешней обёртке SVG,
поэтому оно не перезаписывает поворот начала дуги.

## Демонстрация

Открой `index.html` в браузере или запусти локальный сервер:

```sh
npm start
```

Команда использует Python 3 и открывает сервер на http://localhost:8000.
Устанавливать npm-зависимости не требуется.

В демонстрации поле **Value** управляет значением, переключатели **Animate**
и **Hide** — вращением и видимостью. В портретной ориентации управление
располагается под кольцом, в альбомной — справа.

`scripts/app.js` связывает элементы управления с API; `styles/global.css` задаёт
компоновку демонстрации. Для подключения компонента в другом приложении
эти файлы не нужны.
